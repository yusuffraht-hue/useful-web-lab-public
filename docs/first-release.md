# Baseline release evidence

Screenshot Cleaner passed three regression checks for batch editing, crop coordinates, and ZIP structure. Browser tests verified covers, exports and pixel-redaction on desktop and phone-width Chromium. Signal Garden was solved, undone, and reset in browser tests at both sizes. Physical-device results are unmeasured.

Both apps were first deployed privately. This repository independently rebuilds the same apps before public deployment. Use GitHub's deployment history to find the exact public release commit. Usage is unmeasured.
